# 本土 AI 共學站 ｜ 臺灣主權 AI 語料庫 × 石門國小

把數位發展部「臺灣主權 AI 訓練語料庫」（[taic.moda.gov.tw](https://taic.moda.gov.tw)）的 4,554 筆本土語料，
轉化為一所國小師生家長都能共學的教學應用平台。

🌐 **線上 Demo**：https://cagoooo.github.io/taic-edu/

## 這是什麼

一個**單檔、自包含**的展示型開發計畫網站，示範一位國小老師如何把國家級 AI 語料變成活教材，包含：

- 🔍 **九大教育主題語料探索器** — 從 4554 筆精選 252 筆，對齊 108 課綱領域與議題，標示開放／需申請，每張卡片深連結到語料庫原始頁面
- 👩‍🏫🧒👨‍👩‍👧 **三方共學** — 教師、學生、家長各自的入口與任務
- 📋 **三階段開發藍圖** — 語料導覽站 → 本土 AI 教學助理（RAG）→ 師生共創
- ✨ **六個未來應用想像** — 台語 AI 伴讀、海洋素養探究、在地文化問答機器人…
- ⚖️ **授權與使用須知（教師白話版）**

九大主題：🌊 海洋教育 · 🗣️ 本土語言 · 🎨 文化藝術 · 🏞️ 自然生態 · 👨‍👩‍👧 家庭性別 · 🚸 交通安全 · 📱 媒體素養 · 🏛️ 歷史在地 · 🌱 生命樂齡

## 技術

純 HTML / CSS / JavaScript 單檔（`index.html`），精選語料目錄內嵌為 JSON（資料源 `taic_catalog.json`，2026-06-04 自官方詮釋資料匯出）。無框架、無建置步驟，可直接部署。

## 資料來源與授權

各筆語料之著作權與授權歸原提供機關所有，正式授權條款以
[taic.moda.gov.tw/content/license](https://taic.moda.gov.tw/content/license) 公告為準。
本站為教學應用構想之展示，非官方網站。
